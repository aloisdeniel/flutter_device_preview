in [`images/`](images/) next to this file; regenerate them with

## Post 2 — the integration

> The whole integration is one line:
>
> ```dart
> void main() {
>   DevicePreview.enable();
>   runApp(const MyApp());
> }
> ```
>
> No builder wrapper. No `useInheritedMediaQuery`. No MaterialApp glue.
> Off in release builds — zero footprint ships to your users.

## Post 4 — why it's different

> 3.0 simulates at the engine-abstraction level: a custom WidgetsBinding
> rewrites what the framework itself reads.
>
> So MediaQuery, layout, hit-testing, locale resolution and every package
> you depend on behave exactly as on a real device. No widget-tree tricks.

**Image:** none (this is the architecture post; optionally link DESIGN.md).

## Posting notes

- Attach at most one image per post; X crops previews to roughly 16:9 in
  the timeline, so the tall phone shots display best when tapped — the
  fold and iPad images preview well uncropped.
- Set the alt text given above on each image (accessibility post 7 with no
  alt text would be ironic).
- Post 1 → 10 as one thread; pin post 1 afterwards.
- Good time zones: 15:00–17:00 UTC on a weekday reaches both EU evenings
  and US mornings.
